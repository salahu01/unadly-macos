# Changelog

All notable changes to Unadly for macOS are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-10-10

### Changed

- New app icon: a white shield with a green U.
- The licence and About window now name the copyright owner, salahu01 (Swalahu).

## [1.0.0] - 2026-10-10

### Added

- Web browser built on WebKit with ads blocked inside the engine: about 42,000 ad servers,
  blocked before requests leave the Mac, plus hiding of empty ad slots.
- Popup and popunder blocking: windows a page opens without a click are dropped.
- Home page with search (DuckDuckGo) and pinned sites with their icons.
- Pin the current site with the star button or <kbd>⌘D</kbd>.
- Downloads saved to the Downloads folder without overwriting existing files.
- Video and full screen, as in Safari.
- Keyboard shortcuts: <kbd>⌘L</kbd> address bar, <kbd>⌘R</kbd> reload, <kbd>⌘[</kbd> / <kbd>⌘]</kbd>
  back and forward, <kbd>⇧⌘H</kbd> home, <kbd>⌘N</kbd> new window.
- Opens web links passed on the command line or dropped on the Dock icon.
